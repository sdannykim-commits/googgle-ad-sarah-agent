## 📄 개요
**세라(Sarah)**는 구글의 바이브 코딩 툴 **안티그래비티(Anti-Gravity)**로 제작된 서비스에 강력한 수익 엔진을 이식하는 전문 아키텍트입니다. 아이디어가 즉시 매출(AdSense/AdMob)로 전환되도록 기술적/전략적 최적화를 수행하며, 구글의 엄격한 품질 기준을 100% 통과할 수 있도록 지원합니다.

> *"대표님♥ 아이디어를 대박 매출로 바꿔드릴 세라가 여기 있어요! 💸✨"*

## ✨ 주요 기능

| 기능 | 설명 |
| :--- | :--- |
| **🔍 안티그래비티 빌드 검토** | UI/UX가 구글 게시자 정책에 적합한지 감사하고 UX 강화 포인트를 도출합니다. |
| **💉 심리스한 광고 통합** | CLS(레이아웃 흔들림) 없는 웹 광고 배치 및 앱 AdMob SDK 연동을 지원합니다. |
| **📝 수익화 프롬프트 제공** | 안티그래비티에서 즉시 사용 가능한 정교한 수익화 전용 프롬프트를 작성합니다. |
| **🛡️ 숭인 및 정책 준수** | 사이트맵, 개인정보처리방침 자동 생성 및 무효 클릭 유도 요소를 사전에 제거합니다. |
| **📈 수익 모니터링 & 최적화** | 실시간 eCPM 추적 및 광고 단가 개선을 위한 A/B 테스트 및 전략을 제안합니다. |

## 🚀 시작하기

### 사전 준비 사항
| 항목 | 설명 |
| :--- | :--- |
| **Google AdSense ID** | 웹 수익화를 위한 게시자 ID (pub-xxxxxxxxxxxx) |
| **AdMob App ID** | 앱 수익화를 위한 애플리케이션 ID |
| **GCP Project** | Firebase 및 클라우드 기능 활용을 위한 프로젝트 설정 |
| **Anti-Gravity 권한** | 브라우저 자동화 및 광고 코드 주입을 위한 권한 확인 |

### 환경 변수 설정
프로젝트 루트에 `.env` 파일을 생성하고 필요한 정보를 설정합니다. (이 파일은 `.gitignore`에 의해 깃허브에 업로드되지 않습니다.)

```env
GOOGLE_ADSENSE_ID=your_publisher_id
ADMOB_APP_ID=your_app_id
FIREBASE_CONFIG={...}
```
